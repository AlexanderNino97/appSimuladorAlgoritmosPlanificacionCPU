# 🏦 Simulador de Algoritmos de Planificación de CPU

Proyecto universitario y pedagógico para el estudio práctico de algoritmos de planificación de CPU en Sistemas Operativos, utilizando una metáfora de atención en ventanilla bancaria (Caja CPU, Clientes y Fila VIP).

El código fuente completo de la aplicación se encuentra en el directorio [`simulador/`](file:///simulador/).

## 🚀 Inicio Rápido

Para instalar dependencias e iniciar el simulador:

```bash
cd simulador
npm install
npm run dev
```

O directamente desde la raíz del proyecto:
```bash
npm --prefix simulador install
npm run dev
```

Consulte el manual técnico completo y pedagógico en [`simulador/README.md`](file:///simulador/README.md).
